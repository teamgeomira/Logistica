# 🌱 Malanga - Gestión Agrícola Colaborativa

Aplicación web para gestionar un proyecto de siembra, cultivo, cosecha y venta de malanga entre 3 socios, con sincronización en tiempo real.

## Tecnologías
- Firebase Authentication (email/contraseña)
- Firebase Realtime Database
- Cloudinary (carga de archivos)
- HTML5 + CSS3 + JavaScript ES Modules
